**Abstract**: As smartphones age, file fragmentation worsens progressively, causing I/O degradation and foreground stuttering that directly harms user experience. Existing defragmentation methods typically consider only file hotness or fragmentation level, neglecting user interaction context and application priorities. As a result, user-critical files remain highly fragmented while non-critical files are over-defragmented, unnecessarily accelerating storage wear. To address the above problem, this paper proposes LightDefrager, a lightweight and effective defragmentation mechanism. Its core idea is to maximize user-perceived benefit under a minimal defragmentation budget by selectively relocating high-value files. LightDefrager consists of three modules: 1) Context Value Awareness Module analyzes user interactions to assign a scenario value weight to each scenario; 2) Defragmentation Decision Module integrates usage patterns, scenario value weight, and fragmentation level to compute a composite file value; 3) Action Execution Module prioritizes high-value file migrations and performs them during idle periods under a strict storage-wear budget. Experimental results demonstrate that, compared to the conventional F2FS defragmenter, LightDefrager significantly reduces daily data migration overhead by 86.2% and lowers the UI jank rate by 73.0% relative to the baseline system without defragmentation.
